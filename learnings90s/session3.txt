Basic Linux Commands
====================
1. ls --> list all subdirectories and files in the current directory

2. ls -l --> list all subdirectories and files in the current directory with detailed file information

3. touch filename --> to create a file (touch devops.txt)

4. cat filename --> to view the coontent of the file on the terminal

5. cat > filename --> to enter text to the file

6. cat >> filename --> to append the text to the file

7. tca filename --> displays text in the reverse order

8. cat file1 file2 > file3 --> contents of file1 and file2 will be copied to file3

9. mkdir foldername --> to create a directory or folder

10. what if mkdir devops used twice?
    mkdir devops --> for the first time folder will be created
    mkdir devops --> second time throws error "File exists"
    mkdir -p devops -->  second time if you use "-p" it will not throw the error, also don't create the folder as it already exists

11. rmdir folder --> deletes the directory if it is empty

12. rm filename --> deletes the file from the current directory

12. rm -r folder --> recursive deletion of files inside directory and then directory

13. cp source destination --> copying file from source location to destination

14. mv source destination --> moving the file from source location to  destination location

15. mv file1 file2 --> renaming file1 as file2

Downloading files:
=================
16. wget url --> downloads the file to current directory

grep: searching the given text
==============================
17. grep search_text filename --> searches the given text (case sensitive) in the given file and displays the lines with text

18. grep -i search_text filename --> searches the given text (case insensitive) in the given file and displays the lines with text

19. grep -in search_text filename --> searches the given text (case insensitive) in the given file and displays the lines with text and line numbers

20. grep -ic search_text filename --> searches the given text (case insensitive) and gives the count the lines

21. grep -iv search_text filename --> searches and displays all the lines that doesn't contain given text

curl:
=====
22. curl url --> displays the content of the url file directly on the terminal, whereas wget just downloads the file

23. curl -o temp.txt url --> downloads the text to to temp.text

piping:
====== 
24. command 1 | command 2 --> output of command 1 becomes the input command 2
    example curl url | grep devops --> searching the devops word in the output of curl

Head & Tail:
===========
25. head filename --> displays first 10 lines of file

26. tail filename --> displays last 10 lines of file

27. head -n 14 filename | tail -n 4 ---> displays lines 10 to 14 on terminal
